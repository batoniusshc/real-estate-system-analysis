# Система учета сделок риелторского агентства

## Описание проекта

Моделирование информационной системы для учета сделок риелторского агентства.
Система предназначена для работы риелторов и администраторов.

## Цель

Анализ требований и моделирование бизнес-процессов системы.

## Функциональность

* Авторизация пользователей
* Управление объектами недвижимости
* Создание и сопровождение сделок
* Формирование документов
* Генерация отчетности
